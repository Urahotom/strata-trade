# 検証結果の記録（FINDINGS）

バックテストから得られた「判断材料」を、再現条件つきで記録していく文書。
**这里是事実の記録であって、戦略採用の正当化材料ではない**（DESIGN §3.9 の
定位: 過去最適化の禁止）。

## 記録のルール（再現性の原則）

1. **条件カード必須**: 結果には必ず「完全な実行コマンド（`--history-end` と
   `--cash` を明示で）」「データ provider」「期間」「初期資金」
   「1トレードコスト C」「戦略パラメータ」「実行日」「バージョン」を添える。
   yfinance は**取得日に依存してデータが変わる**ため `--history-end` 固定が必須。
   `report.md` 冒頭に条件カードが自動出力される
2. **条件一致・再現確認**: 同じ条件で再実行し、出力が一致することを
   確認できて初めて結果は「記録済み」とみなす
3. **金額と割合の両記**: 平均利益・平均損失などは金額と買付金額比の両方で載せる
4. **期間分離**: 学習・調整に使った期間（2015–2020）と最終評価期間
   （2021〜）を分けて記録する。**採点対象は最終評価期間のみ**
5. 平均リターンだけでなく **年率（CAGR）・MDD の区間と回復（水没）日数・
   投資時間** をセットで載せる

## データ整合性（2026-10-24 適用。以降の全記録に共通する前提）

P10 のオーバーレイ検証中に、yfinance 系列の**分割未調整**が検証結果を
根本から壊していたことが判明した。問題は2層あった。

1. **登録分割が未調整だった**（F-003 初回・F-004 初回の実行時）:
   プロバイダが `close` をそのまま使っていたため、登録分割日（例:
   9984 の 2024-12 分割）が真实の -75% 暴落として系列に残っていた。
   → **`adjclose`（遡及調整済み）を優先使用するよう修正**（data/yfinance.py）
2. **プロバイダが知らない分割・不正ティック**（1306.T だけ実測）:
   2015-01-05 の水準 1/10 への**持続的**段差（events メタデータなし、
   adjclose も未調整）と、2026-03-30〜31 の 2 日間だけの 1/10 レベル応答
   （翌日復帰）。→ **研究パス限定の修復 `repair_split_jumps()`**（data/repair.py）を
   追加。判定は「ジャンプ後 5 営業日その水準が持続するか」— 持続すれば
   分割とみなして**その日より前の全履歴を同率再スケール**、一過性なら
   前日値で置換。実運用パス（1日エンジン）は引き続き validate.py が
   異常値で取引を中断する安全側設計（修復しない）

修正後の再実行で主要な数値は大幅に変化した（例: F-003 の ma_cross
B&H超過は初回 −297.7pt → −460.1pt、donchian は「決済ゼロ・+344%」→
「39往復・+28.3%」）。**旧数値は破棄し、以下が修復後の正式記録**である。
修復が効いた銘柄はキャッシュ 31 銘柄中 1306.T のみ（147 本）で、
30 銘柄は adjclose 修正の影響のみを受けた（チェック済み）。

### F-004 のポイント

1. **学習期間で最適化したパラメータでも、16窓中13窓は等額B&Hに負けた**。
   勝ちはすべて 2025 窓に集中（3戦略が同時に勝つ＝相場由来の解釈が自然で、
   「手法が勝った」Evidence はない）。データ修復後は 2025 窓の勝ち幅が
   大きくなった（rsi +95.1pt）が、単一窓・単一相場への依存に変わりはなく、
   **平均では rsi の +2.0pt を除き全戦略マイナス**
2. **選択パラメータが窓ごとにフラフラ**（ma_cross の選択は 20→10→5→5 と
   安定せず）。学習結果が不安定ということは、パラメータ最適化自体が
   ノイズの追尾という F-003 の疑いは supported
3. **銘柄数を30に広げてもクロスセクション・エッジは出ない**。1銘柄MAで
   なく数十銘柄横断でこそ出るはずのエッジが検定されなかったことになる
4. **B&H(30) は指数比で年に3〜12pt高い**（2019: +32.6% vs TOPIX +19.9%）。
   現在上場銘柄を遡って選ぶ**生存者バイアスの実測**であり、等額B&H相手の
   判定はかなり厳しい側。TOPIX ETF比でも勝年是数える程度は同じ
5. **判定（重ねて）: 現行4戦略に実運用（P5）を裏付ける根拠はない**。
   「パラメータを直す」方向は否定された。次があるとすれば方向の違い —
   常時ロングのB&Hに対する**オーバーレイ**（暴落検知で撤退する、ボラ目標で
   株数を落とす 等「リターンを捨ててDD/回復期間を買う」設計）。ma_cross が
   MDDを半減できた事実に接続する検証として F-005 を設計した
6. 弱点: 生存者バイアス（④）は未除去。評価窓が4つ・各1年で少なめ。
   yfinance 配当込み調整済みベースのため分散配当銘柄のリターンはやや甘い側

## F-005: リスクオフ・オーバーレイ vs 素のB&H（F-004 の帰結の検証）

F-004 が「常時ロングの等額B&Hに勝てない」と確定したため、最後の方向
「リターンを捨てて DD/回復期間を買う」＝**指数B&Hに対するオーバーレイ**を
指数そのもの（1306.T TOPIX ETF・配当込み）で検証した。戦略の勝敗ではなく
**P5（自動発注）を開設する価値があるか**の判定が目的。

### 条件カード（再現キー）

```

uv run python scripts/overlay_vs_buyhold.py
（既定: 1306.T / 2014-06-02〜2026-10-23 / 資金 10,000,000 円 /
  片道コスト 0.050 %（SOR無料＋スリッページ見積。感度表で無コストも併記）/
  判定=当日終値・執行=当日終値（翌日から反映・未来参照なし）/
  パラメータは古典値固定: 200日MAフィルタ / MA50x200クロス / 目標ボラ20%（20日））

実行日: 2026-10-24 / ブランチ feat/p10-riskoff-overlay

```

### 全期間 12.4年

| 方針 | 総return | 年率 | MDD | 水没日数 | 投資時間 | 切替/年 | vs B&H |
|---|---|---|---|---|---|---|---|
| **素のB&H** | **+394.6%** | **+13.77%** | 32.7%（回復済） | 1,056 | 100% | 0 | — |

評価窓（年の切り出し）で最も「保険」が機能した 2025 年でも:
B&H +26.8%/MDD 17.7%/水没 64日 に対し、200日MAは +20.7%/**MDD 7.9%**だが
**水没 197日**（再エントリー遅延で回復が一番長い）。MAクロスは +12.8% で
MDD 削減ゼロ。コスト感度（無コスト→片道0.050%）は 200日MA で −10.6pt、
他は −3.4pt 以下（ボラ目標は年54.7回の切替が効く）。

### F-005 のポイント

1. **3オーバーレイとも全期間で素のB&Hに大敗（−176〜−291pt）した一方で、
   MDDは最大でも 6.6pt しか改善しない**。「DD保険」の保険料（待機中の
   上昇取り逃し: 投資時間 68〜69%）が明らかに割に合わない
2. **水没日数はむしろ悪化し得る**（MA50x200: 1,330日 > B&H 1,056日、
   2025窓: 197日 > 64日）。トレンドフィルタは「底で戻り、高値で遅れる」
   ため、回復を早めるという売り文句はこのデータでは不支持
3. **ボラ目標は切替コストが実質的な足枷**（年54.7回×片道0.05% ≈ 年5.5%
   相当が感度表に現れる）。MDD 削減は 2.2pt のみ
4. 2014〜2026 のTOPIX は MDD 32.7% を 3年で Fully Recovery しており、
   そもそも**「保険を買うほど長い傷」がこの期間に存在しなかった**
   （B&H 水没 1,056日が上限）。保険の需要がない市場で保険の値踏みをした
   結果、とも言える。日本以外の長期低迷市場での再検証は未実施
5. **判定: P5（自動発注）は開設しない**。常時ロング指数B&H（ほったらかし）
   に対し、戦略もオーバーレイも正当化する根拠が出ない。本システムの位置づけは
   「観察・研究インフラ＋手動運用の補助」となり、発注権限の付与は
   「B&H を確実に上回る手段が見つかったとき」に据え置く
   （DESIGN §1 の非目標に追記済み）

## F-006: ML騰落確率戦略（参照ソフトの投資判断のクリーンルーム再実装）

F-004/F-005 で「現行4戦略・オーバーレイとも等額B&Hに勝てない」が確定した後、
外部の公開ソフト **hajime-f / stocktrading（CC BY-NC 4.0）** が採用する
投資判断 — 「テクニカル特徴量から翌日が ±閾値以上 動く確率を教師あり分類で
予測し、確率が高い銘柄で張る」 — を、考え方を参照して**独立再実装**し
（`strata.strategy.ml_probability.MLProbabilityStrategy`）、同じ walk-forward
土俵で等額B&H・ランダム対照・確率校正として検証した。

**ライセンス**: 元実装の TensorFlow / Keras BiLSTM のコード・構成はコピーして
いない（著作権で保護される「表現」を移していない）。骨格のアイデアだけを、

  評価年 2019,2021,2023,2025 / band ±0.50% / ラベル lag=1（t+1→t+2・約定整合）/

データキャッシュ: var/reports/p9_bars.json（F-004 と同一。sha256 先頭16桁

**指標の定義（今回訂正）**：**投資時間＝在市場日割**（1株でも保有した日）。
**平均Eクスポ＝資金投入率**（`market_value/equity` の期間平均）。この2つは別物。
**return/exp ＝ リターン ÷ 平均Eクスポ**（市場に置いた金1単位あたりの成果）。
ただし return/exp は投入タイミング・集中度・複利を正規化しない**荒い物差し**なので、
選択スキルは「ランダム対照40通りの分布に対する**分位**」で見る（下表 B）。

**約定整合（今回追加）**: 戦略はシグナル日 t の**翌営業日終値**で約定（NEXT_OPEN
近似）するため、モデルは約定後に実現する変動 `t+1→t+2` を予測させる `lag=1` を既定に
した。従来の `t→t+1`（`lag=0`）は予測が約定前に完了する非実行系で、E で対照する。

### F-006 のポイント（監査・対照・校正・horizon を反映して訂正）

1. **当初の「投資時間19%＝市場に居ない」は計測誤り**（訂正）。評価期間だけで測ると
   投資時間 78〜100%・平均Eクスポ（資金投入率）も 0.55/0.60 では 50〜94% と
   **実はフル投資に近い**。「投資時間が足りない」では説明できない
2. 敗因は投資量ではなく、**Headline return の大半が期末建玉の含み益**で、実現損益は
   窓により符号が異なり小幅（A表）。ただし**含み益が市場ベータだけか選択スキルを含むかは
   未分離**（TOPIX比や同一保有集合に対する超過での帰属は未実施＝弱点6）。閾値0.70は
   発注が少なく含み益すら薄い
3. **選択スキルの証拠は得られなかった**: 約定整合の `lag=1` で return/exp の
   ランダム40通り分位が **1/4 のみ中央（52%）、他は 15〜35%でランダム以下**。断定は避け
   「この実装・条件では選択スキルを示す証拠なし」とする（return/exp は荒い物差しであり、
   同一保有集合の直接比較は弱点6に譲る）
4. **校正が崩れている**: 予測 0.7 以上帯の実現は多くが 3〜5 割で過信。閾値 0.7 は
   「70%の確信」ではなく目盛りが甘い。日次予測は自己相関で実効サンプルは件数より少ない。
   絶対値のまま閾値を発注基準にできない（校正し直すなら未使用窓で再評価が必要）
5. **約定horizon**: 既定 `lag=1`（約定後に実現する t+1→t+2 を予測）に訂正し、ラベルの
   境界リーク（評価期初の終値が学習ラベルに漏れる）も塞いだ。E のとおり、非実行系の
   `lag=0` だけ年により分位 60〜75%と上向きに見えるが、**実行系では中央以下に沈み**、
   horizon を直しても tradable な優位は現れない
6. **判定: 採用不可（P5ゲート不開設）**。ただし結論の範囲は「**MLP・ロングオンリー・
   このリスク予算サイジング・約定終値近似**」まで。BiLSTM/L/S そのものの否証でも
   優位性の「不在証明」でもない（4窓は検定力が小さく「証拠が見つかっていない」が正確）
7. 弱点: 生存者バイアス未除去・評価窓4つ・MLP は BiLSTM と別物（長期系列依存 未特徴化）・
   校正（Platt/isotonic）やクラス不均衡の詰めは未実施・**ベータ/アルファの帰属分離と
   同一保有集合での選択効果の直接比較は未実施**（return/exp は代理指標）。コスト感度は D で
   ざっくり計測済み（結論不変・悪化方向）。CC BY-NC の非営利制約は実売買になると論点（非断言）

## 付記: 手数料に関する注記（SOR）

- 証券会社側の方針として、**市場選択に「SOR」を指定した新規発注は
  現物・信用を問わず手数料無料**（信用の無料サービスは廃止方向だが SOR
  新規発注の無料は継続）
- 当システムは全注文が既定 `exchange=9`（SOR）。東証(1)指定も SOR へ読み替える
  ため（DESIGN §2・api/models.py）、**エンジンが出す注文は原則すべて無料対象**
- 帰結: バックテストの「手数料なし」は近似ではなく実態と一致。実コストは
  **成行スリッページ**（未モデル）に集約され、無料化でその相対的存在感は増す
- 無料は「新規発注」のみ。信用決済・現引き・振替など免費対象外の取引を
  手動運用する際は留意

既定は **3,000 万円ではなく 300 万円**（3,000,000 円）。数値自体は当時の
実行結果と一致（金額は資金線形なので率指標は不変）だが、条件カードの欠落・
