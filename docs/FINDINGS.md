# 検証結果の記録（FINDINGS）

バックテストから得られた「判断材料」を、再現条件つきで記録していく文書。
**这里是事実の記録であって、戦略採用の正当化材料ではない**（DESIGN §3.9 の
定位: 過去最適化の禁止）。

## 記録のルール（再現性の原則）

1. **条件カード必須**: 結果には必ず「完全な実行コマンド（`--history-end` と
   `--cash` を明示で）」「データ provider」「期間」「初期資金」
   「1トレードコスト C」「戦略パラメータ」「実行日」「バージョン」を添える。
   yfinance は**取得日に依存してデータが変わる**ため `--history-end` 固定が必須。
   `report.md` 冒頭に条件カードが自動出力される
2. **条件一致・再現確認**: 同じ条件で再実行し、出力が一致することを
   確認できて初めて結果は「記録済み」とみなす
3. **金額と割合の両記**: 平均利益・平均損失などは金額と買付金額比の両方で載せる
4. **期間分離**: 学習・調整に使った期間（2015–2020）と最終評価期間
   （2021〜）を分けて記録する。**採点対象は最終評価期間のみ**
5. 平均リターンだけでなく **年率（CAGR）・MDD の区間と回復（水没）日数・
   投資時間** をセットで載せる

### F-003 のポイント

1. **期間を分けると「全期間の良さ」の正体が見える**。bollinger/donchian の
   学習期間リターンは**マイナス**（−31.9%/−34.4%）。全期間 +394%/+344% は
   2021 年以降のベータで取り返した混合値であり、期間分離しなければ見えなかった
2. **rsi_reversion の矛盾が確定した**: 学習期間は E 負（構造負け）、
   評価期間は E 正だが 5 回・投資時間 50.5% で「たまたま大きく空けて
   居直った」程度の確度。期間をまたぐ一貫性がない＝エッジでなくパラメータ運
3. **回復（水没）日数は MDD の深さより厳しい制約になり得る**: B&H の水没は
   787日だが、逆張り2戦略は 1,209〜2,782 日と 1.5〜3.5 倍。「下落時の痛みが
   小さい」どころか、傷からの回復が最も遅い
4. **ma_cross は唯一評価期間の一貫性が確認できた**（学習期間 E+2,652 →
   評価期間 E+28,476、両期間でプラス）が、年率 9.92% は評価期間の B&H との
   対照がまだ無い（下記課題）
5. donchian の評価期間 +343%（年率 29.3%）は E が**負**（−33,663円/回）で
   投資時間 93%。クローズ戦略として負けているのに保有ベータで数字が良い
   典型。**含み益は戦略の腕前ではない**
6. **検定の弱点（次回の課題）**:
   - 期間分離実行に**期間別ベンチマークが無い**（評価期間の年率 9.92% が
     良いのか悪いかをまだ言えない）→ 期間別 B&Hold を追加すべき
   - 分割日が 1 本だけ。ロールする walk-forward の自動化が必要
   - 各期間のトレード数が一桁。E・勝率の信頼区間が広い
   - 2銘柄の後知恵・生存者バイアス、スリッページ未モデル（手数料は SOR
     無料で実態一致）は F-001 から未解決

## 付記: 手数料に関する注記（SOR）

- 証券会社側の方針として、**市場選択に「SOR」を指定した新規発注は
  現物・信用を問わず手数料無料**（信用の無料サービスは廃止方向だが SOR
  新規発注の無料は継続）
- 当システムは全注文が既定 `exchange=9`（SOR）。東証(1)指定も SOR へ読み替える
  ため（DESIGN §2・api/models.py）、**エンジンが出す注文は原則すべて無料対象**
- 帰結: バックテストの「手数料なし」は近似ではなく実態と一致。実コストは
  **成行スリッページ**（未モデル）に集約され、無料化でその相対的存在感は増す
- 無料は「新規発注」のみ。信用決済・現引き・振替など免費対象外の取引を
  手動運用する際は留意

## 履歴（F-001・F-002 は打撃。F-003 が現行の正式記録）

### F-001（2026-10、v0.2.1）: 2015〜 実データ 4戦略 vs Buy&Hold 初回比較

全期間の総return・B&H超過のみの初回表（ma_cross +92.8%/超過−297.7pt、
rsi +8.3pt、bb +3.4pt、donchian −46.4pt）。教訓: 「この期間の主役はベータ」
「超過＋3〜8pt はトレード数 5〜7 では統計的に無意味」。

**正誤**: 当時の記録は初期資金を「1,000 万円」としていたが、実際のスクリプト
既定は **3,000 万円ではなく 300 万円**（3,000,000 円）。数値自体は当時の
実行結果と一致（金額は資金線形なので率指標は不変）だが、条件カードの欠落・
`--history-end` 未固定がまさに今回の再構成で潰した問題だった。

### F-002（2026-10、v0.2.1+P8）: MDD区間・期待値分解・投資時間の初導入

日次評価額の MDD が rsi 59.9% > B&H 50.3%（下落を守れていない）、
rsi の E=−12,650 円/回（W<L の構造負け）、投資時間 73〜99% などを検出。
詳細（金額・割合・回復期間込み）は F-003 に統合。

### 使い方の教訓（チェックリスト・最新版）

- ①条件カード一致と再現確認 ②B&H超過（全期間**と評価期間**）
  ③トレード数のサンプル十分性 ④別期間・期間分離での再現
  ⑤MDD 区間・**回復（水没）日数** ⑥E 分解の符号と W:L 比率（金額と割合両方）
  ⑦投資時間（上昇相場の現金放棄か、下落回避の失敗か）
- 金額だけ見て満足しない。年率とベータ比に直してから判断する
